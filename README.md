MediNova is a full-stack healthcare web application that helps users book appointments with doctors online. It provides secure authentication, doctor management, appointment scheduling, and an admin dashboard for managing the platform.

## 🚀 Features

- User Authentication (JWT)
- Doctor Registration & Management
- Book Appointments Online
- Admin Dashboard
- Secure Backend APIs
- Cloudinary Image Upload
- MongoDB Database Integration
- Responsive UI

## 🛠️ Tech Stack

### Frontend
- React JS
- CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication
- Cloudinary
